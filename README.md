# 🏆 Copa 2026 — Artilharia e Resultados
Projeto desenvolvido com o objetivo de aplicar conceitos de separação de responsabilidades em aplicações web utilizando HTML, CSS, JavaScript e JSON, explorando boas práticas de organização, manipulação de dados dinâmicos e renderização de conteúdo interativo.

## 📌 Objective
Gerenciar e visualizar os principais dados da Copa do Mundo 2026 através de uma aplicação web.
A aplicação permite:

Exibir a artilharia com fotos, gols e assistências dos jogadores

Mostrar o pódio dos 3 principais artilheiros

Consultar a tabela de classificação dos grupos

Visualizar os resultados dos jogos por fase

Pesquisar jogadores por nome ou seleção

Interagir com os dados em tempo real via JSON

## ⚙️ Technologies
HTML5

CSS3 (Flexbox & Grid)

JavaScript (ES6+)

JSON (dados dos jogadores e partidas)

Fetch API

Responsividade com CSS

## ▶️ Execution
Basta abrir o arquivo index.html em um navegador moderno.
Os dados são carregados dinamicamente a partir de profile.json (artilharia) e arrays JavaScript (jogos e grupos).

## 🗄️ Database
Bando de dados não relacional
Os dados são mantidos em JSON e arrays JavaScript, simulando uma API REST.
